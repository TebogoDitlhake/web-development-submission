# DJI Osmo Pocket 3 — Web Development Workbook Project

A responsive e-commerce product showcase and interactive web application built for the Web Development Workbook, featuring the **DJI Osmo Pocket 3**.

## Project Structure

* **`Product.html`** — Main product landing page featuring semantic HTML5 layout, product overview, package comparisons, pricing, and customer reviews.
* **`Specs.html`** — Detailed technical specifications page linked directly from the main product overview.
* **`Task 4.html`** — Responsive multi-device package grid layout built using the Bootstrap 12-column grid system and CSS media queries.
* **`Task 5.html`** — Interactive product customizer demonstrating real-time two-way data binding (`v-model`) using Vue.js.
* **`/Images/`** — Product photography and package assets (`dji-pocket-3.jpg`, `dji-pocket-3-side.jpg`, `pocket3-standard.jpg`, `pocket3-creator.jpg`, `pocket3-vlogger.jpg`).

## Technologies Used

* **HTML5:** Semantic structure (`<header>`, `<main>`, `<section>`, `<footer>`), accessible image attributes, and structured comparison tables.
* **Bootstrap 5:** Responsive 12-column grid (`col-lg-4`, `col-md-6`, `col-sm-12`), flexbox utilities, and card components.
* **Vue.js:** Declarative rendering and real-time two-way data binding via the `v-model` directive.

## How to View

1. Open `Product.html` in any modern web browser (or view via the live GitHub Pages deployment).
2. Ensure the `/Images` folder remains in the same root directory as the `.html` files so all product visuals load properly.
